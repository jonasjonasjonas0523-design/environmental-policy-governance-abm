# Public reproducibility-record hierarchy

For scientific interpretation of this repository, use the following authority order:

1. **Model/equation authority:** `V1_2_LOCKED_PARAMETERS.md`, `V1_2_IMPLEMENTATION_SPECIFICATION.md`, and `AMENDMENTS_V1_2.md`.
2. **Computational authority:** `FINAL_COMPUTATIONAL_AUDIT.md`.
3. **Final numerical reporting:** `MANUSCRIPT_INTEGRATION_SUMMARY_FINAL.md`, `ROBUSTNESS_REPORT.md`, `f3_report.md`, and `v12_v5prime_report.md`.
4. **Archetype placement:** `ARCHETYPE_PLACEMENT_MEMO.md`, subject to `FINAL_SUBMISSION_DECISIONS.md` for WGI vintage and final manuscript-linkage decisions.
5. **Output manifest:** `RESULTS_MANIFEST_FINAL.md`.

Known correction: the first summary table in `FINAL_READOUTS.md` contains an erroneous mixed/no-dominance column. Use the computational audit as authority. Correct mixed/no-dominance counts are reference 1368, k010 1401, k055 1433, h050 1333, h095 1470.

Historical v1.1 values may appear where the versioning record explicitly discusses superseded specifications. They are not final v1.2 parameters.
